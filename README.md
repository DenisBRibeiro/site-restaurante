# 🍽️ Restaurante do Bairro

Um site simples de cardápio para restaurante desenvolvido com **HTML5 e CSS3**, apresentando refeições, bebidas e sobremesas em um layout responsivo.

## 🌐 Demo

Acesse o site publicado:  
https://denisbribeiro.github.io/site-restaurante

## ✨ Funcionalidades

- Menu de navegação por seções
- Layout responsivo
- Organização dos produtos em **CSS Grid**
- Botão de contato via **WhatsApp**
- Design simples para cardápio digital

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- CSS Grid
- Google Fonts
